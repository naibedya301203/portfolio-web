# 💼 Responsive Personal Portfolio Website

A modern, clean, and fully **responsive personal portfolio website** built using **HTML, CSS, and JavaScript**.  
This project is designed to showcase your **skills, projects, experience, and contact information** in a professional way.  
Perfect for students, developers, and freelancers who want an online presence.  

---

## 🚀 Features

- Responsive design for desktop, tablet, and mobile  
- Smooth navigation with a sticky header  
- Hero section with personal introduction  
- About section to highlight your background and skills  
- Projects/Portfolio section with showcase cards  
- Contact section with social media links and form  
- Simple, fast, and lightweight (no external frameworks)  

---

## 🛠️ Tech Stack

- **HTML5** – Semantic page structure  
- **CSS3** – Styling, Flexbox, Grid, Media Queries  
- **JavaScript (Vanilla)** – Interactivity and animations
